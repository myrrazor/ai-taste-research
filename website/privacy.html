Privacy

No cookies. No account. Nothing from your machine reaches this site.

This page covers the public website and the local software it describes. Effective 16 September 2026.

What this website collects

Nothing through the pages themselves. There are no cookies, analytics scripts, advertising pixels, session replay, accounts, payments, or contact forms. Embedded video on How it works is a file served from this same site, not a third-party player.

The site is static files hosted on Vercel. Like any web host, Vercel may keep request logs (time, path, IP, user agent) under Vercel’s privacy policy. This project does not run its own log analysis on those records.

What stays on your computer

NanoTaste is a local Python CLI. Taste files, likes, unlikes, run records, reports, and ingested session excerpts live under the project directory you point it at, usually as TASTE.md, taste/, and .nanotaste/. The localhost studio at 127.0.0.1:7468 talks only to that machine. This website cannot see any of it.

One CLI behavior to know about: unless you pass --taste-file, NanoTaste searches upward from the working directory for TASTE.md, so it can read a parent directory’s taste file.

What harvest reads

If you opt a source in during setup, nanotaste harvest (and ingest) reads user-visible session artifacts from that source on disk: Cursor, Claude Code, Codex, Continue, Aider, Windsurf, Cline, Gemini CLI, Zed, OpenHands, Amazon Q, GitHub Copilot, git history, and existing NanoTaste records. It writes redacted excerpts locally. It does not upload them here.

Before storage, excerpts replace secret-like spans (tokens, API keys, private key blocks), email addresses, and home-directory usernames, then clip the text. Caps in the current tree: 800 characters per excerpt, 500 excerpts total, 200 files per source, 256 KiB per ingest file. Redaction is a filter, not a guarantee. Do not point harvest at material you cannot keep on the machine.

nanotaste learn --apply is the explicit step that merges learned rules into TASTE.md. Scheduled harvest writes overlays under taste/learned/ and does not rewrite seeded category files on its own.

Seeds from URLs, files, and notes

nanotaste seed --url fetches an http(s) page you name, with a NanoTaste user-agent, and stores a local excerpt. It rejects URLs that carry credentials. File and image seeds stay on disk; images use the caption and filename, not a vision model. Pasted notes are stored as you typed them, after the same redaction pass.

If you write to the project

Questions go through the public GitHub issue tracker. GitHub’s privacy terms apply. Do not paste personal taste files, private prompts, session logs, or secrets there.

Deleting local data

There is no site profile to delete. Remove .nanotaste/ and, if you want the taste tree gone too, TASTE.md and taste/ from the project directory. Uninstalling the package does not delete those files.

Changes

If this site starts collecting anything, this page will change first. Right now the honest description is: static files, host logs we do not control, and a local program whose records never leave your machine unless you copy them.
